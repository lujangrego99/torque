# Password incorrecta y usuario inexistente → el MISMO 401 genérico (no revela cuál falló)

$ pedir '' POST /api/auth/login '{"email":"mecanico1@torque.local","password":"incorrecta-123"}'
{"error":"Credenciales inválidas."}
HTTP 401


$ pedir '' POST /api/auth/login '{"email":"nadie@torque.local","password":"incorrecta-123"}'
{"error":"Credenciales inválidas."}
HTTP 401

# Entrada inválida → 400

$ pedir '' POST /api/auth/login '{"email":"mecanico1@torque.local"}'
{"error":"Datos inválidos o incompletos.","detalles":["password es obligatoria."]}
HTTP 400
